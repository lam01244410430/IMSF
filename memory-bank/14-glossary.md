# Glossary
| English term | Definition | Storage identifier |
|---|---|---|
| Household | Shared ownership and authorization boundary | household_id |
| Ledger entry | Posted change to an account balance | account_ledger_entries |
| Inventory lot | Stock received together with a common cost and expiry | inventory_lots |
| Inventory movement | Traceable change to stock quantity | inventory_movements |
| Disposal | Removal from stock with a reason | disposal_records |
| FEFO | First expiring, first out | FEFO |
| Waste cost | Disposed quantity valued at lot cost | waste_cost |

Use English snake_case database identifiers and stable enumeration codes. Maintain localized terms in interface resources.
